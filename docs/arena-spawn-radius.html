1. Le plus loin dans l'écran, c'est un coin

Depuis le centre de l'écran, le point visible le plus éloigné est un coin. La distance centre → coin, c'est l'hypoténuse du triangle violet (Pythagore) :

√(540² + 960²) ≈ 1101 px

C'est la moitié de la diagonale de l'écran. Tout point plus loin que ça du centre est forcément hors de l'écran.

2. Phaser fait le calcul

const view = camera.worldView;
// distance centre → coin, + une marge pour cacher l'ennemi entier
const spawnRadius = Phaser.Math.Distance.Between(
  view.centerX, view.centerY, view.right, view.top) + 128;

Phaser.Math.RandomXY(offset, spawnRadius);
enemy.enable(view.centerX + offset.x,
             view.centerY + offset.y);

3. Centré sur la vue, pas sur le joueur

Amène le joueur contre un bord : la caméra s'arrête, le joueur n'est plus au centre de l'écran. Un cercle centré sur le joueur passerait dans l'écran.
